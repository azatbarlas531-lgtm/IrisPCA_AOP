# Iris PCA ve AOP Projesi

Bu projede Iris veri seti üzerinde PCA (Principal Component Analysis) uygulanmıştır.

Proje kapsamında:

- Iris veri seti CSV dosyasından okunmuştur.
- PCA analizi gerçekleştirilmiştir.
- Özdeğerler hesaplanmıştır.
- Sonuçlar grafik ile görselleştirilmiştir.
- LoggingAspect kullanılarak loglama işlemleri yapılmıştır.
- TimingAspect kullanılarak zaman ölçümü gerçekleştirilmiştir.
- ValidationAspect ile veri doğrulama işlemleri yapılmıştır.
- ExceptionAspect ile hata yönetimi sağlanmıştır.
- PerformanceMetrics ile performans ölçümleri gerçekleştirilmiştir.

Kullanılan Teknolojiler:
- Java
- Maven
- Apache Commons Math
- JFreeChart
- AspectJ
